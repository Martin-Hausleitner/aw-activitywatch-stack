# Public OpenClaw Skills

This directory contains sanitized, public skills related to the ActivityWatch local lifelog stack.

## Included

- `activity-watch` — read-only ActivityWatch analysis and local summary helper

## Not included

Privacy-sensitive or account-specific skills are intentionally not published here:

- messaging skills
- business/finance workflows
- Apple Photos search
- private Martin-only skills
- any credential-bearing config

## Safety rule

Skills in this directory must not contain:

- personal credentials
- private absolute paths
- raw ActivityWatch data
- mailbox/message content
- health exports
- phone numbers or personal identifiers
